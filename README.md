# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

做一个给剧场灯光师使用的灯位与Cue表管理前端项目，可以维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和Cue触发顺序。页面需要有舞台平面灯位图、Cue列表、当前场景预览、灯具筛选和演出版本备注，适合排练期间快速调整。

## 技术栈

React + Vite + TypeScript

## 排演模式

- 按光位（面光/侧光/逆光/效果光）筛选灯具，舞台平面图同步淡化其他光位
- 选中灯具后可调整通道号、色片、焦点位置、亮度预设，舞台图与当前场景预览实时更新
- Cue 列表支持新增、改名、上移/下移排序，序号按位置自动保持连续
- 移除被 Cue 引用的灯具时会被阻止，并列出相关 Cue，灯具与顺序保持原样
- 所有排演调整自动保存为本地草稿（localStorage），可一键放弃草稿恢复初始数据

## 目录结构（数据 / 规则 / 界面分离）

- `src/data/` 初始演出数据与色片表
- `src/domain/` 类型定义与纯业务规则（Cue 排序、移除守卫、指标统计）
- `src/state/` 本地草稿读写与排演状态 hook
- `src/components/` 舞台图、Cue 列表、灯具编辑、场景预览等界面组件

## 本地运行

```bash
npm install
npm run dev
```
